1. Create the Project with Latest Vite and Node 24.21.0 
	>> npm create vite@latest skch-hrmsone-app -- --template react
	>>ESLint
2. Run the Project using >>npm run dev
	It will run in local port http://localhost:5173
3. Tab favicon and Project Name change in index.html 
4. Remove the code App.jsx , App.css and inedex.css
	Create Arrow function in App.jsx >> rafce
5. .env file for environment values inside project root folder
		import.meta.env.VITE_API_URL
6. Install Required node modules
    --npm list @mui/material
    --npm ls @mui/material @mui/x-date-pickers dayjs
    >>npm install @mui/material@9.5.0 @emotion/react @emotion/styled
    >>npm install @mui/icons-material@9.5.0
    >>npm install @mui/x-date-pickers@^9 dayjs
    >>npm install @mui/x-data-grid
    >>npm install react-icons
    >>npm install formik yup
    >>npm install @reduxjs/toolkit react-redux
    >>npm install react-toastify

7. To Apply Same Font for Entire Project 
    --> Add CSS Style in index.CSS
    --> Create a theme.js and Wrap it in main.jsx it will apply to all MUI Components

8. Create the Components folder inside that Create the common Components
	--> Button
	--> Dropdown (AutoComplete)
    --> Typography 
    --> Chatbot
    --> Popup

9. create styles folder > globalStyles.jsx to apply the gobal styles 

10. To change the Default port number add server port in vite.config.js

11. Configure redux store, create store folder in that create store.jsx file and to configure the store 
    then Inject the store to Application in main.jsx using Provider 

12. Configure Tostify in main.jsx using ToastContainer
